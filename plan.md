структура выполнения

вся память идет с привязкой к комнате. все комнаты самостоятельные.


2 уровня задач:
глобальная задача
- обновить контроллер
- построить здание
- спавн крипа
- захват комнаты
- разведка
и другие

для каждой глобальной задачи делаем подзадачи
- конкретный крип берет н ресурсов из а и идет делать б 
 (крипу в очередь ставтся 2-3 примитивные задачи)

задачи верхнего уровня появляются из событий
задачи нижнего - ставит диспетчер из задач верзнего уровня. 
для задачи верхнего уровня отлслеживаем % выполнения.

События:
    GAME_START
        -> Разведка
        -> Обновить контроллер 
        -> первичные спавн крипов
    RCL_CHANGE 
        -> Построить доп здания, которые можно построить при новом RCL
        -> Обновить контроллер 
    GCL_CHANGE 
        -> Захват новой комнаты
    CREEP_DIES 
        -> Спавнить крипа, если нужно.
    HOSTILE_CREEP_APPERS
        -> Спавним атакующего для защиты

Менеджмент ресурсов.
есть источники (источник, контейнер, куча)
и потребители (стройка, контроллер, спавн, экстеншены, башня, и прочее)

источнки работают по принципу бронирования
если не удалось забронировать - уменьшаем таргет по универсальным крипам, но не чаще чем раз в 300 тиков. 
задачу на спан крипа ставим (если нужно) раз в 300 тиков, но сразу на всю необходимое количество.
